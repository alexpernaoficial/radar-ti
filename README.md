# Radar TI

Site de estudos e notícias sobre IA, gestão de TI, ITSM e o mercado de provedores de internet.

- **Notícias:** uma reportagem por dia sobre IA, gestão de TI e de serviços (ITSM). Quando há notícia relevante de provedores de internet, ela entra junto.
- **Aulas de ISP:** uma aula por dia sobre o negócio de provedores: mercado, métricas, gestão, tecnologia e futuro.
- Tema claro e escuro, português e inglês, busca em todas as edições.

O conteúdo é produzido com apoio de inteligência artificial a partir de fontes públicas, que ficam listadas em cada texto. Confira nas fontes antes de usar.

## Como funciona

Site estático (sem servidor). A página `index.html` lê os arquivos `data/edicoes.json` e `data/aulas.json`. Cada nova edição entra por commit nesses arquivos, e o GitHub Pages publica sozinho.

Todos os exemplos usam empresas fictícias ou dados públicos citados com fonte. Nenhum dado de empresa, cliente ou colega é publicado aqui.
